Quick setup guide
📱 Add ScoreTracker to your Home Screen

Save ScoreTracker to your phone so you can open Dominoes & Spades with a single tap.

scoretracker.webhitsdesign.com
🍎 iPhone / iPad — Safari
  1. Open scoretracker.webhitsdesign.com in Safari.
  2. Tap the Share button (square with an upward arrow). If you don't see it, open Safari's page menu.
  3. Scroll and tap Add to Home Screen. If it isn't visible, look under Edit Actions.
  4. Keep the name ScoreTracker, then tap Add.
  5. Launch ScoreTracker from the new icon on your Home Screen.
🤖 Android — Chrome
  1. Open scoretracker.webhitsdesign.com in Chrome.
  2. Tap the three-dot menu in Chrome.
  3. Choose Add to Home screen or Install app (the wording may vary).
  4. Tap Install or Add to confirm.
  5. Tap the ScoreTracker icon on your Home Screen to start playing.
💡 Good to know

Adding the shortcut is free. Game history is saved in this device's browser storage and does not automatically sync across devices. Install the app from the custom domain to keep using the same address.

Default winning goal is 350. Each player or team enters a bid from 1–13, chooses Blind if applicable, and records books made. The combined books made across all entries must equal 13 each round.

Round controls

The combined books made for all players/teams must equal 13 before a round can be submitted. No scores change unless all players/teams total exactly 13 books. Select a number from 0–13 for bids and books made. Undo last round restores the previous round.
